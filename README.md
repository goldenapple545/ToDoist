# ToDoist

Простой список дел на сегодня для Windows: красивое полупрозрачное «стеклянное» окно,
сквозь которое видно обои. Никаких регистраций, аккаунтов и интернета — всё локально.

![иконка](src/ToDoist.ico)

## Что умеет

- **Окно без рамки**: скруглённые углы, тень, полупрозрачный фон (обои просвечивают).
- **Слайдер плотности стекла** внизу окна — от «прозрачнее» до «плотнее».
  Меняется только тинт, текст остаётся полностью читаемым: у стекла всегда есть неснижаемая «вуаль».
- **Тема автоматически как в Windows** (светлая/тёмная) + акцентный цвет системы для галочек и прогресса.
  Кнопка `☀` переключает вручную: авто → светлая → тёмная.
- **Задачи дня**: пишете в поле сверху, `Enter` — задача появляется в списке.
  Клик по задаче отмечает её выполненной (зачёркивание), кнопка справа удаляет.
- **Незакрытые дела не теряются**: вчерашние невыполненные остаются в списке с пометкой
  «вчера» / «3 дня назад», а выполненные за прошлые дни скрываются — список дня не мусорится.
- **📌 поверх всех окон** — удобно держать список рядом с работой.
- **Всё сохраняется само** в `%APPDATA%\ToDoist\data.json` (задачи, тема, прозрачность,
  позиция и размер окна, закрепление).

## Стекло

Фон карточки — это обои Windows, размытые и чуть более сочные: «жидкое стекло» как в iOS.

- Обои читаются один раз и кэшируются, насыщенность поднимается, а размытие (гауссово, радиус 34)
  считает видеокарта средствами WPF — процессор почти не задействован.
- Под карточкой видно **именно ту** часть обоев, что лежит за окном: учитываются стиль
  (по центру, растянуть, вписать, заполнить, замостить) и положение окна на экране.
- Поверх размытия лежат слои: тинт (плотность задаёт слайдер), верхний блик, очень мелкое зерно
  (убирает полосы на градиентах) и светлая кромка с «преломлением».
- Скругления (20 px) и мягкая тень остаются своими: окно прозрачное, поэтому углы гладкие.
- Размывается только рабочий стол — как Mica в Windows 11; окна за спиной не подмешиваются.

Если в Windows выключены эффекты прозрачности или система старше Windows 10 1803,
приложение само переходит на прежнее сплошное стекло. Режим можно задать принудительно
(`ToDoist.exe --backdrop=blur|solid|auto`), а активный режим виден в подсказке кнопки темы `☀`.

## Требования

- Windows 10/11.
- .NET Framework 4.8 — он уже есть в Windows 10/11, доустанавливать ничего не нужно.
- Для сборки — PowerShell (есть всегда). MSBuild, Visual Studio и .NET SDK **не нужны**:
  сборка идёт встроенным компилятором C# из .NET Framework.

## Сборка и запуск

```powershell
# собрать (бин\ToDoist.exe + тесты)
powershell -ExecutionPolicy Bypass -File .\build.ps1

# запустить
powershell -ExecutionPolicy Bypass -File .\run.ps1

# создать ярлык на рабочем столе
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Готовый файл: `bin\ToDoist.exe` — его можно просто копировать куда угодно и запускать двойным
щелчком (нужен только .NET Framework 4.8, который в Windows уже есть).

## Горячие клавиши и мышь

| Действие | Как |
|---|---|
| Добавить задачу | `Enter` в поле ввода или кнопка `+` |
| Отметить выполненной | клик по галочке или по тексту задачи |
| Удалить задачу | кнопка корзины у задачи (появляется при наведении) или `Delete` для выбранной |
| Фокус в поле ввода | `Ctrl+N` |
| Скрыть окно | `Esc` (в пустом поле ввода или когда фокус не в поле) |
| Перетащить окно | за шапку (заголовок «Сегодня, …») |
| Изменить размер | потянуть за любой край или угол окна |
| Свернуть / закрыть | кнопки `—` и `✕` в шапке |

## Где лежат данные

```
%APPDATA%\ToDoist\data.json   — задачи и настройки (обычный читаемый JSON)
%APPDATA%\ToDoist\error.log   — журнал: если что-то пошло не так, смотрите здесь
```

Если файл данных окажется повреждён, приложение не упадёт: он будет переименован в
`data.json.corrupt-ГГГГММДД-ЧЧММСС`, а приложение стартует с чистого списка.

## Структура проекта

```
src/MainWindow.xaml          разметка окна, стили и слои стекла (грузится через XamlReader)
src/MainWindowController.cs  логика окна: задачи, hotkeys, сохранение, перетаскивание
src/ThemeManager.cs          авто-тема, палитры, акцент из реестра Windows, кисти стекла
src/ResizeHelper.cs          изменение размера окна без системной рамки
src/Storage.cs               атомарное сохранение/чтение JSON
src/AppData.cs, TaskItem.cs  модель данных и её нормализация
src/Log.cs, Program.cs       точка входа и логирование
src/BackdropSupport.cs       выбор режима стекла, плотность тинта, область обоев
src/GlassSupport.cs          пиксельные операции: зерно, размытие, насыщенность
src/WallpaperGlass.cs        обои → кисть размытия под карточкой
src/app.manifest             PerMonitorV2 DPI + поддержка Windows 10/11
src/ToDoist.ico              иконка приложения (генерируется tools\IconMaker.cs)
tools/IconMaker.cs           утилита, рисующая иконку
tests/StorageTests.cs        самопроверка хранилища (32 проверки)
tests/BackdropTests.cs       проверки логики стекла (50 проверок)
build.ps1, run.ps1, install.ps1
```

## Технические заметки

- Сборка — легаси-компилятором `csc.exe` из .NET Framework 4.0/4.8, поэтому код написан
  в синтаксисе C# 5 (без `$"..."`, `?.`, expression-bodied-методов).
- WPF-сборки берутся из GAC: в папке .NET Framework их нет, `build.ps1` сам находит пути.
- Исходники — UTF-8 **без BOM**, поэтому компиляция идёт с флагом `/codepage:65001`,
  иначе русский текст превратился бы в кракозябры.
- Скрипты `*.ps1` наоборот должны оставаться **чисто ASCII**: Windows PowerShell 5.1 читает
  файлы без BOM как CP1251 и падает на UTF-8 кириллице в комментариях.
- XAML лежит в exe как embedded resource и загружается `XamlReader.Load` — MSBuild не нужен.
- Окно с `AllowsTransparency=True` не имеет системной рамки, поэтому изменение размера
  реализовано вручную (`ResizeHelper`).
- Клип стеклянных слоёв ставится на карточку, а не на внутренний `Grid`: у элемента
  с `Effect` (тень) и клипом-потомком WPF может вовсе не нарисовать содержимое.
- Системный акрил DWM в WPF-окне не виден: при `AllowsTransparency=False` поверхность окна
  непрозрачна и перекрывает размытие (проверено и `DWMWA_SYSTEMBACKDROP_TYPE` на Windows 11,
  и `SetWindowCompositionAttribute`), поэтому фон размывает сама карточка.
